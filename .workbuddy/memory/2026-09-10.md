# 2026-09-10

## 构建 flutter_variety_chart 包（v0.1.0）

从零原创实现了一个 Flutter 图表包，替代"把 syncfusion_flutter_charts 改名"的做法
（后者是商业授权代码，改名复制仍属侵权，已明确拒绝并改为原创实现）。

### 交付物
- 包本体：`lib/flutter_variety_chart.dart` + `lib/src/{models,render,painters,widgets,behaviors,analysis,utils}`
- 全平台 example：`example/`（android / ios / web / linux / macos / windows），
  10 个演示页覆盖全部系列类型
- 测试：`test/` 下按模块拆分 12 个测试文件，127 个用例全部通过
- `README.md` / `CHANGELOG.md` / `LICENSE`(MIT) / `analysis_options.yaml`

### 能力范围
- 直角系列：折线(直/曲/阶梯/快速)、面积、区域面积、柱状、区域柱、条形、散点、
  气泡、K线、高低、高低开收、瀑布、直方图
- 堆叠：`VarietyStackingMode.none / normal / percent100`
- 圆形系列：饼图、环形、径向条
- 特殊：漏斗、金字塔、迷你图(线/面积/柱/涨跌)
- 轴：数值 / 类别 / 日期时间 / 日期时间类别 / 对数 + 绘图带 + 多级标签
- 行为：提示框、轨迹球、十字准线、缩放平移、选择
- 分析：趋势线(线性/指数/对数/多项式/幂/移动平均) + 11 种技术指标
- 标注：文本/线/矩形/椭圆/箭头/图片

### 关键架构决策
1. **元素流渲染**：布局把数据转成 `VarietyElement` 列表，painter 只遍历列表绘制。
   新增系列类型不需要改 painter。见 `lib/src/render/variety_elements.dart`。
2. **单一布局双消费者**：同一个 geometry 对象同时供绘制与命中测试使用，
   所见即所得。
3. **条形图自动转置**：当全部系列都是 `VarietyBarSeries` 时，
   `VarietyCartesianGeometry` 自动交换主轴/次轴语义，把点改写为
   `(value, categoryIndex)`，使数值轴水平。`transposed` 为 true 时
   取值必须用 `geometry.valueAt()` 而不是 `data.y`。
4. **零依赖**：日期格式化、回归、技术指标全部自己实现，不依赖 intl。

### 踩过的坑（重要）
- `VarietyChartData.copyWith(y: null)` 会**保留**原值（Dart 的 `?? this.y` 语义）。
  指标预热点必须用新增的 `withValue(null)`。
- `GestureDetector` 里无条件注册 `onDoubleTapDown` 会让每次单击都延迟到
  双击超时（300ms）。缩放行为未启用时不应注册 scale/doubleTap 处理器。
- 转置模式下 `_buildPositions` 的纵坐标必须取**类别索引**，不是数值。
- `@immutable` 来自 `package:flutter/foundation.dart`，`painting.dart` 不导出它。

### 本机环境注意事项
- 环境里设置了 `http_proxy` / `https_proxy`（127.0.0.1:49214），会破坏
  `flutter_tester` 的本地 WebSocket，导致 `flutter test` 报
  "Invalid WebSocket upgrade request"。运行测试前必须清掉：
  `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy flutter test`
- `flutter analyze` 极慢（本次首跑约 8 分钟）；迭代时用 `dart analyze lib test`（约 20 秒）。
- 离线 pub 缓存位于 `E:/flutter_pub_cache`。`example/` 的离线依赖解析会因
  `vm_service` 求解失败，因此手动基于根包的 `.dart_tool/package_config.json`
  生成了 `example/.dart_tool/package_config.json`（补 `flutter_variety_chart`
  与 `variety_chart_example` 两条）。用户在有网环境直接 `flutter pub get` 即可。
